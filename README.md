# 📖 Overview

The COVID-19 pandemic generated one of the largest publicly available datasets in modern history. Understanding its spread requires more than visualization—it requires statistical analysis, forecasting, and geographical exploration.

This project demonstrates an end-to-end data science workflow that collects COVID-19 data, performs exploratory and statistical analysis, builds forecasting models, and presents findings through interactive dashboards.

The objective is to understand infection trends, evaluate vaccination impact, identify regional hotspots, and forecast future case trajectories using modern data science techniques.

# ⚙ Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/covid-pandemic-analysis.git
```

Create a virtual environment and install dependencies:

```bash
python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt
```

Run the analysis:

```bash
python main.py
```

Launch the dashboard:

```bash
streamlit run dashboard/app.py
```
